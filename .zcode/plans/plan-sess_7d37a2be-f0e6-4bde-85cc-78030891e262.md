# AI Degen Trader — subfolder, standalone page, explicit decision-model core

**What this is:** a personal AI agent that trades like a skilled human degen: filters new pairs, researches narrative/community/holders, watches the tape, buys the momentum after the initial-dip nuke, sells by judgment. No TA indicators, no stop-loss orders, no sizing math. Setuh's playbook = first trader spec.

## The Decision Model (our own, Jev-role) — the core
- **Typed decision contract** at every decision point (qualify / arm / re-look / exit): input = decision vector (Setuh filters, our forensics, tape state, narrative fields, vision reads); output = `{action: buy|arm|watch|skip|exit|hold, p_up: 0–1, conviction: 0–1, reasons: enum[], trap_params}`. Bounded rationale, zero free text in hot paths. Substrate: GLM Flash (Z.ai, ~1s, fractions of a cent; one key you already have; env-pluggable override). Schema/prompts/versioning all ours, in `degen/`.
- **Calibration + abstention:** every p_up journaled vs realized outcome; reliability/Brier recalibration; "abstain" is a first-class action (documented Jev-class failure = overconfidence on contested cases).
- **Distillation endpoint:** once `trader_journal.jsonl` has enough labeled decisions→outcomes, train our own small local classifier (GBM, sub-ms, deterministic, backtestable in the repo's replay pipeline). GLM engine stays as analyst + fallback; the distilled model is the endgame brain, 100% ours.

## Three-tier runtime around the decision model
- **Reflex tier (0ms, pure code):** armed traps only. Decision model already made the buy decision at arm-time; the trigger (nuke ≥X% off high toward floor + momentum resume: N consecutive up-ticks + buy/sell volume flip + nuke-low reclaim; aborts: bundles still distributing, floor lost) fires the pre-authorized local swap in milliseconds. LLM never in this loop.
- **Decision/analyst tiers (GLM Flash for live decisions, GLM flagship + vision for research):** qualification, trap params, position re-looks, chart vision (real dip vs knife-fall, fake staircase, toppy-or-alive), narrative/community research. All tool-calling code is ours (raw RPC/Helius; vendor scores cross-check only).
- **Review tier (GLM):** post-trade + nightly reflection → playbook note the decision model re-reads.

## Execution split
- Latency-critical (nuke snipes): local programmatic executor, code-signed Jupiter/PumpSwap swap, broadcast <1s.
- Slow plays: Terminal browser lane, confirm mode — agent fills panel, you sign. Playwright profile you log into once.

## Location & UI
`pump-chart/degen/` self-contained: `feed.py` (Setuh filters + final-stretch scanner), `research.py`, `vision.py`, `decision.py` (typed contract + calibration + journal), `agent.py`, `traps.py`, `terminal_driver.py`, `router.py`, `web/index.html` + `degen.js` — standalone page at `http://localhost:8000/degen`, not a tab; dashboard untouched; `main.py` integration ≈3 lines. Journal: `degen/journals/trader_journal.jsonl`.

## Loop
FILTER (Setuh table + final-stretch 85-95% bonded) → RESEARCH (analyst) → LOOK (vision) → DECIDE (decision model, typed, journaled) → arm trap / watch / skip → EXECUTE (reflex fires locally; slow = browser confirm) → MANAGE (Flash re-looks, exit by judgment) → REVIEW (reflection → playbook) → DISTILL (Phase 2: train our own model from the journal).
